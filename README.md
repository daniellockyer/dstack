# 🤠 dstack

The agent skills I use daily.

My focus is **performance and scalability**: keeping websites fast and
available as they grow.

> [!NOTE]
> This repo is a work in progress. Skills are coming soon.

> [!TIP]
> These skills are focused on performance and scalability. For general code
> development, I'd recommend [pstack](https://github.com/cursor/plugins/tree/main/pstack)
> by [@poteto](https://x.com/poteto), a much wider set of rigorous engineering
> workflows.

## Install

Add the skills with [`npx skills`](https://github.com/vercel-labs/skills):

```sh
npx skills add daniellockyer/dstack
```

To pick a single skill, or install for your user instead of the project:

```sh
npx skills add daniellockyer/dstack --skill ooda-loop
npx skills add daniellockyer/dstack --global
```

Run `npx skills add daniellockyer/dstack --list` to see what's available.
